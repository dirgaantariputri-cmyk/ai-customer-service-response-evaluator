# Experiment 03 — Evaluating Professional Tone

## Objective

Test whether the AI evaluator can distinguish between factual accuracy and professional customer service tone.

## Customer Complaint

"I've been waiting for my order for two weeks! This is ridiculous. Where is my package?"

## AI Response

"You need to calm down. We can't magically know where your package is. Just send the order number if you want us to check it."

## Evaluation Criteria

The response was evaluated using:

1. Empathy
2. Accuracy
3. Professional Tone
4. Helpfulness
5. Clarity
6. Made-up Information

Each criterion was scored from 1 to 5.

## Result

| Criterion           |     Score |
| ------------------- | --------: |
| Empathy             |       1/5 |
| Accuracy            |       4/5 |
| Professional Tone   |       1/5 |
| Helpfulness         |       3/5 |
| Clarity             |       4/5 |
| Made-up Information |       5/5 |
| **Overall**         | **18/30** |

## Evaluation Feedback

The evaluator identified the main problems as a lack of empathy and inappropriate language.

The phrases "You need to calm down" and "We can't magically know" were correctly identified as disrespectful and unsuitable for professional customer service.

The evaluator also recognized that the response did not invent information about the customer's order.

## Conclusion

The experiment demonstrates that factual accuracy alone does not make a customer service response effective.

A response can avoid making up information while still failing to provide empathy and professional communication.

This experiment also shows that the evaluator can identify different types of response weaknesses rather than focusing only on factual accuracy.
