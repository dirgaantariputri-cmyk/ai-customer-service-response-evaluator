# Experiment 01 — Baseline Response Evaluation

## Objective

Test whether the AI evaluator can correctly evaluate a customer service response using the six defined criteria.

## Customer Complaint

"I've been waiting for my order for two weeks! This is ridiculous. Where is my package?"

## AI Response

"I'm sorry your order is taking so long. I understand how frustrating it must be to wait two weeks for your package. I can help check the status of your order. Please provide your order number or tracking number so I can look into it."

## Evaluation Criteria

The response was evaluated using:

1. Empathy
2. Accuracy
3. Professional Tone
4. Helpfulness
5. Clarity
6. Made-up Information

Each criterion was scored from 1 to 5.

## Result

| Criterion           |     Score |
| ------------------- | --------: |
| Empathy             |       5/5 |
| Accuracy            |       5/5 |
| Professional Tone   |       5/5 |
| Helpfulness         |       5/5 |
| Clarity             |       5/5 |
| Made-up Information |       5/5 |
| **Overall**         | **30/30** |

## Evaluation Feedback

The evaluator considered the response strong because it acknowledged the customer's frustration, offered a useful action, and did not invent information about the order.

The evaluator also suggested making the response slightly more direct about checking the order status after receiving the order or tracking number.

## Conclusion

The evaluator successfully identified the strengths of the response and produced scores consistent with the expected evaluation.

This establishes a baseline for future experiments with weaker customer service responses.
